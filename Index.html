Company profile & banking
These print on the quotation letterhead. Add up to 3 bank accounts below — the one marked "Primary" prints on quotations.
Cross-device use: this file works fine on both computer and mobile browsers, but there's no automatic sync between them (that needs a paid cloud server, which a downloadable file can't provide). To move your data to another device: click Export all data below, send yourself that file (WhatsApp/email/drive), open this same suite file on the other device, then click Import data.
PDF attachments (on leads) are stored on this device only, using your browser's local file storage — they are not included in the JSON backup above and won't carry over to another device automatically. Re-attach on the other device if needed.
Due-date alerts: the banner at the top of Leads/Sales Ledger shows automatically whenever you open the app and something is overdue or due today. You can also turn on a system notification for the same, below — this only fires while the app is open in your browser (a closed browser or app can't be notified, same reason as the sync point above).
